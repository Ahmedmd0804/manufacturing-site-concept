## 🌐 Overview & Description

### 🏭 TitanForge Industries

**Manufacturing & Heavy Machinery Website Concept**

This website was built as a full manufacturing website concept rather than just a single landing page. The idea was to create a complete digital presence for a heavy machinery company, from the first hero section all the way through products, industries, capabilities, projects, insights, company information, and contact.

The design leans heavily into an industrial / technology feel with a dark interface, grid backgrounds, glowing accents, technical typography, machinery imagery, animated elements, and a lot of small interactions throughout the experience.

### What I worked on

- Designed the overall website structure and user experience
- Built the frontend and responsive layouts
- Created the navigation and page flow
- Built product and machinery sections
- Created industry-specific content sections
- Added custom manufacturing workflows
- Built featured project / case study sections
- Added industry insights and filtering
- Created the About and leadership experience
- Added company timeline and values sections
- Built the contact and inquiry experience
- Added responsive mobile navigation
- Added animated counters and visual effects
- Added typing and loading animations
- Added scroll-based animations
- Added interactive buttons and cards
- Added local storage behavior for the demo experience
- Added URL hash-based navigation
- Worked through responsive and UI issues
- Deployed the website for live demonstration

## 🏗️ Main Sections

### ⚙️ Machines

A product-focused section covering different types of industrial equipment and machinery.

Examples include:

`CNC Machining Centers` · `Hydraulic Presses` · `Robotic Welding`  
`Laser Cutting` · `Gear Hobbing` · `Material Handling`  
`Injection Molding` · `Surface Treatment`

---

### 🛠️ Custom Manufacturing

A dedicated flow showing how a custom manufacturing project can move from:

**Consultation → Design → Prototype → Production → Delivery**

The section also covers engineering design, control systems, precision parts, fabrication, testing, and retrofit / upgrade services.

---

### 🏭 Industries

Created dedicated experiences around different manufacturing industries including:

`Automotive` · `Aerospace` · `Oil & Gas` · `Energy`  
`Construction` · `Pharmaceutical` · `Food Processing` · `Railway`

---

### 📊 Featured Projects

Added detailed case-study style sections to show how the website could present manufacturing projects and their outcomes.

The project experience includes:

- EV battery frame welding
- 5-axis aerospace machining
- Hydraulic press manufacturing
- Wind turbine gearbox production

Each section uses project-specific content, visuals, industry labels, and supporting metrics.

---

### 📰 Industry Insights

Added an insights area for manufacturing and technology-related content.

Topics include:

- Collaborative robots
- Predictive maintenance
- IoT
- Advanced manufacturing materials
- CNC machining
- Digital twins
- Machine safety

The section also includes category-based filtering for:

`Technology` · `Automation` · `Industry 4.0` · `Materials`

---

## 🎨 Design Direction

I wanted this one to feel different from a typical corporate manufacturing website.

The visual direction combines:

`Industrial` · `Futuristic` · `Technical` · `Cyber / Digital` · `Manufacturing`

The interface uses a dark base with bright accent colors, grid patterns, technical fonts, glowing borders, animated elements, and industrial imagery.

Typography was also part of the design system, using:

- **Orbitron** for major headings
- **Rajdhani** for general UI/content
- **Share Tech Mono** for technical / system-style elements

---

## 💡 What This Project Shows

For me, this project was less about building another company homepage and more about putting together a complete web experience around a business.

It involved thinking through:

`Business → Content → User Experience → Design → Development → Interaction → Responsive Behavior → Deployment`

There are also a lot of smaller things behind the interface that aren't immediately obvious when looking at the homepage, from navigation state and local storage to animations, filtering, responsive behavior, and client-side interactions.
